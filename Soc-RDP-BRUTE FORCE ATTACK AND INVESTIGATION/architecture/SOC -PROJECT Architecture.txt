Architecture

The project uses a **centralized SOC monitoring architecture where Windows endpoint telemetry is collected using the Splunk Universal Forwarder and Sysmon, then sent to Splunk running on Kali Linux for detection, correlation, visualization, and investigation.

```text
       ▼

       ▼
```


### Components

| Component                      | Role                                                                      |
| ------------------------------ | ------------------------------------------------------------------------- |
| **Windows Endpoint**           | Generates authentication, security, and system activity                   |
| **Sysmon**                     | Provides detailed endpoint telemetry such as process and network activity |
| **Splunk Universal Forwarder** | Collects and forwards Windows logs                                        |
| **Kali Linux**                 | Hosts the Splunk Enterprise SIEM in the lab                               |
| **Splunk Enterprise**          | Central log collection, search, detection, correlation, and visualization |
| **SPL**                        | Used to query and analyze security events                                 |
| **SOC Dashboard**              | Provides visual monitoring and investigation panels                       |
| **SOC Analyst**                | Reviews events, correlates activity, and investigates suspicious behavior |
