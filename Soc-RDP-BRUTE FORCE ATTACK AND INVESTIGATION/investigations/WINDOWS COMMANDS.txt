# Windows Security Events

## Event ID 4625
Failed logon attempt.

## Event ID 4624
Successful logon.

## Logon Type 10
Remote Interactive Logon, commonly associated with RDP.

## Event ID 4634
Logoff.

## Event ID 4672
Special privileges assigned to new logon.
Step 1 — On Windows, verify soc-lab

Open Command Prompt as Administrator and run:

net user soc-lab

Look for:

Account active               Yes
Password required            Yes

If the account doesn't exist, create it:

net user soc-lab YourLabPassword123! /add

For example, you can use a lab-only password that you know.

Step 2 — Give soc-lab RDP permission

Still in Administrator CMD:

net localgroup "Remote Desktop Users" soc-lab /add

You should get:

The command completed successfully.

Then verify:

net localgroup "Remote Desktop Users"

You should see:

soc-lab
Step 3 — Make sure Remote Desktop is enabled

On Windows:

Settings → System → Remote Desktop → Remote Desktop = On

Then run:

netstat -ano | findstr :3389

You want something similar to:

TCP    0.0.0.0:3389    0.0.0.0:0    LISTENING
Step 4 — Check Windows Firewall

Administrator PowerShell:

Get-NetFirewallRule -DisplayGroup "Remote Desktop" | 
Where-Object {$_.Enabled -eq "True"} |
Select-Object DisplayName, Enabled, Profile

If Remote Desktop firewall rules aren't enabled:

Enable-NetFirewallRule -DisplayGroup "Remote Desktop"
